# LifeSnap 前端

前端由 FastAPI 直接提供，无需构建。启动后端后打开其本地地址即可使用。

这次界面围绕日常操作整理为：首页、账单、AI 帮记，以及待办、日记和设置。手机底部保留四个入口，待办和日记也能从首页与“更多”进入。

- 首页集中展示记账方式、本月收支和最近账单。
- 账单先显示可搜索、筛选和翻页的明细，本月统计默认折叠。
- 记账表单突出金额、用途、分类和日期，支付方式与备注选填。
- AI 只展示待核对信息、修改与保存操作；补充信息通过编辑卡片完成。
- 待办默认展示全部未完成事项，包括尚未安排时间的事项。
- 日记没有记录时显示明确空状态；高级设置集中在折叠区域。

原有样式保留在 styles.css，简洁界面的布局和覆盖样式在 usability.css。

## 验证

后端需要已安装 backend/requirements.txt 中的依赖，默认使用 backend/.venv 中的 Python。

在此目录运行：

```sh
npm install
npm run check
npm test
```

测试需要浏览器。Windows 默认使用已安装的 Edge；其他系统先执行 `npx playwright install chromium`。可通过 `PLAYWRIGHT_CHANNEL` 选择浏览器，通过 `LIFESNAP_PYTHON` 指定 Python。

测试会启动独立端口的临时后端，使用系统临时目录保存测试数据，并禁用外部 OCR/模型配置。不会连接现有服务或修改个人账单。退出时关闭临时服务与浏览器，截图目录打印在测试结果中。

检查包括新增与修改、搜索和分页、收支筛选、失败重试、AI 修改后确认入账、无时间待办、日记空状态及保存、图片识别失败补录，以及 320/390/900 像素布局。另检查弹窗内部滚动、提示消失时保留输入和焦点。真实外部模型识别质量不在本次前端测试范围内。
