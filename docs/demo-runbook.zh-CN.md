# 演示脚本

English: [demo-runbook.md](demo-runbook.md) | 简体中文

## 目标

这份脚本用于证明 LifeSnap AI 是一套具备受控 AI 操作能力的财务工作流，而不只是
对话式原型。适合五到八分钟的产品评审或答辩演示。

## 演示前准备

1. 在 8023 端口启动后端，并在干净的浏览器配置文件中打开应用。
2. 准备一张不含敏感信息的收据图片；如果未配置外部图片识别服务，则使用手动录入。
3. 在设置中确认本次要展示的模型配置，演示过程不要展示 API 密钥。
4. 若需展示 RAG 管理，请在本地设置 LIFESNAP_ADMIN_KEY，并在管理员页面创建短期会话。
5. 将 docs/assets/lifesnap-ai-demo-hero.png 作为开场视觉；它应明确标注为概念图，不是
   产品截图。

## 演示流程

### 1. 建立价值认知

打开首页，说明完整闭环：记录账单、理解消费、询问助手、审核每一个写操作、通过反馈
持续改进质量。展示当月收支摘要和最近活动。

### 2. 记录一笔账单

使用手动表单，仅填写金额和账单类型，说明其他字段均可选填。接着上传一张非敏感收据
图片，系统会给出识别字段供核对。如果识别服务不可用，则演示降级提示并手动完成录入。

成功信号：只有在用户明确保存后，记录才会出现在账单列表和仪表盘中。

### 3. 询问消费分析

在 AI 助手页面提问，例如“我这个月的消费情况怎么样？”或“我的预算执行得怎么样？”。

成功信号：助手给出文字评估和可视化所需的消费分析数据，但不会创建或修改账单。

### 4. 安全地展示函数调用

用自然语言让助手记录一笔小额消费，例如“今天午餐花了 28 元”。检查候选账单，修改一项
信息，再点击明确的保存操作。

成功信号：界面展示 Agent 执行步骤，候选项可以修改，且只有确认动作才会真正创建账单。

### 5. 展示 RAG 知识库管理

打开管理员页面，查看现有知识列表。新增或修订一条分类策略，运行知识测试，再展示版本
历史。需要撤回时使用回滚，不直接删除内容。

成功信号：知识管理与普通财务操作隔离，并使用短期管理员会话保护。

### 6. 展示质量与运行保障

对助手回答提交反馈。在管理员区域运行 AI 质量评测，然后打开诊断或可观测性页面，说明
健康信号、追踪中的隐私控制和 Prometheus 指标接口。

成功信号：产品具有质量闭环和运行信号，而不是一次性的模型回答。

## 收尾表述

LifeSnap AI 将结构化个人财务数据与具备受限工具、受管理知识、写操作明确确认和可度量
质量的 AI 助手结合在一起。后续扩展将沿用这些边界，而不是在试点后推翻现有工作流。

## 演示注意事项

- 不展示 API 密钥、原始收据内容或真实个人记录。
- 不承诺 OCR 或分类完全正确，应展示产品刻意设计的核对和纠错流程。
- 若外部模型服务不可用，使用本地降级能力，并说明模型服务健康度可以独立观测。
