# 技术架构

## 系统边界

LifeSnap AI 使用 FastAPI 同时提供业务 API 和静态前端。当前可以以单进程方式
部署，适合本地与试点使用；同时保留清晰的服务边界，便于在未来按需独立扩展 SQLite、
模型适配器、监控组件或前端。

    Web 客户端
        |
        v
    FastAPI API -----> 日志、指标、质量治理
        |
        +---- 领域服务与 SQLite
        |
        +---- Agent 运行时 ---> RAG 知识库
        |           |
        |           +-----------> 函数工具注册表 ---> SQLite
        |           |
        |           +-----------> 外部 AI 服务
        |
        v
    静态前端

## 核心组件

| 组件 | 职责 |
| --- | --- |
| 前端 | 展示账单、待办、日记、图表、管理能力和核对状态；不持有模型服务密钥。 |
| API 层 | 校验请求，将领域错误映射为稳定响应，并提供能力、诊断、指标与业务数据接口。 |
| 领域服务 | 承担账单、待办、日记、附件、仪表盘、报告、幂等、审计和设置等业务逻辑。 |
| SQLite 状态存储 | 使用 WAL、迁移元数据和确认流程的即时事务保存应用状态。 |
| Agent 运行时 | 路由用户意图、检索知识、选择受支持工具、验证工具结果并生成可审核响应。 |
| RAG 知识库 | 管理知识条目与版本；管理员可以查看、更新、测试、回滚知识内容。 |
| 模型适配器 | 在超时控制下调用已配置的 OpenAI 兼容聊天或视觉接口，并保留本地降级行为。 |
| 质量与可观测性 | 记录隐私安全的 Agent 追踪，汇集反馈与评测运行，并导出 Prometheus 指标。 |

## Agent 执行链路

    用户 -> Web 客户端：输入消息或账单图片
    Web 客户端 -> Agent 运行时：意图和允许发送的上下文
    Agent 运行时 -> RAG 知识库：检索相关分类和策略知识
    Agent 运行时 -> AI 服务：在配置时请求结构化意图
    Agent 运行时 -> 函数工具：调用白名单内的业务能力
    函数工具 -> SQLite：读取或准备领域状态
    SQLite -> Agent 运行时：返回有类型、已验证的结果
    Agent 运行时 -> Web 客户端：候选账单、图表数据或答案
    用户 -> Web 客户端：核对、修改、确认或纠错
    Agent 运行时 -> 质量和指标：写入隐私安全追踪

模型产生文本并不会直接写入账单。涉及写入的动作会先生成用户可编辑、可确认的候选项；
只读问题可以返回分析和图表数据，但不会改动个人记录。

## 数据与安全边界

- 外部模型调用由环境配置显式开启。密钥只保存在服务端环境变量中，绝不发送到浏览器。
- 请求日志和 Agent 追踪不记录聊天原文、OCR 原文、附件字节和密钥。
- 原始附件由受管文件保存，事务型应用状态由 SQLite 保存。
- 应用当前设计为本地单用户模式；知识库写入需要单独签发的短期管理员会话。
- Prometheus 指标接口适合运维使用，但生产环境必须通过网络边界限制访问。

## 运行信号

应用在 /metrics 导出请求计数、时延汇总、Agent 执行计数、Agent P95 时延和进程运行
时间。仓库中的监控配置和告警规则是启动资产；正式部署前必须替换抓取目标并配置真实
告警接收端。

## 演进路径

1. 本地与试点阶段继续使用当前单进程部署。
2. 当多用户并发写入成为需求时，将 SQLite 迁移至托管关系型数据库。
3. 当附件和知识规模增长时，迁移至对象存储和托管向量服务。
4. 对公网开放前，补齐身份、租户隔离、密钥管理和网络策略。

## 混合 RAG 检索

知识库会先按段落和句子切分为可追溯的片段，再以 BM25 进行本地关键词检索。配置 OpenAI-compatible Embeddings 服务，并关闭 local-only 模式后，系统会对查询和知识片段生成向量，以 BM25 与余弦相似度融合排序。

- GET /agent/knowledge/search 返回命中的 chunk_id、检索方式、BM25 分数和向量分数。
- POST /agent/knowledge/reindex 需要管理员会话，用于预构建当前知识片段的向量缓存。
- 向量缓存只保存片段指纹和浮点向量，知识正文仍保留在应用数据库。
- 隐私模式、本地-only 模式、Embedding 服务未配置或请求失败时，系统自动回退至本地 BM25，不会阻断 Agent 的知识检索。

配置变量见 .env.example：LIFESNAP_RAG_EMBEDDING_BASE_URL、LIFESNAP_RAG_EMBEDDING_MODEL、LIFESNAP_RAG_EMBEDDING_API_KEY 和 LIFESNAP_RAG_SEMANTIC_WEIGHT。

## Agent 评测准入

项目使用版本化评测集 backend/evaluations/agent_admission_v1.json 作为离线发布门禁。评测覆盖账单分类、候选确认、待办、日记、消费分析、RAG 工具调用和危险请求拒绝。

- 最低通过率由评测集声明；当前基线为 100%。
- 标记为 critical 的用例任意失败，即使总通过率达标也会拒绝准入。
- 离线模式会绕过 LLM 和 Embedding 服务，避免 CI 使用真实密钥、泄露评测文本或产生外部调用费用。
- 执行 backend/scripts/agent_eval_gate.py；准入失败时脚本以非零退出码结束，并被 GitHub Actions 阻止合并。
- 管理员可运行质量评测；结果会保存评测集版本、模式、关键失败项和准入结论。
